# Bringing in your chapters

Choose [Import Chapters…](#do=import-chapters) and pick a folder of Word (`.docx`) files, one for each chapter.

## What RT Press reads

- **The order** comes from the last number in each file's name, when every file has one. Otherwise the files are taken in name order.
- **The chapter's title** is its first line. A leading "Chapter 3:" is taken off.
- **Italic and bold** are kept. Indented paragraphs are read as documents inside the story, such as letters.
- **Curly quotes** are set from the text around them.

## Notes from the import

If something looks wrong, such as a quotation mark with no partner, the import says which file it is in. RT Press sets the words as they are written, so fix them in your Word files and import again.

Your Word files are only read. RT Press never changes them.
