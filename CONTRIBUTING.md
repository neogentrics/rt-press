# Contributing

Thanks for your interest in yes!

This is **proprietary software** (see [LICENSE](LICENSE)). The source is public for transparency, but **code contributions are
by invitation only**. Please don't open pull requests unless you've been asked to.

Please don't fork the project to publish your own version or send changes back without asking first. Knowing who is building on the code is how we keep unwanted or harmful changes out.

You are very welcome to:

- **Report bugs.** Open an issue. Say what happened, how to make it happen again, and your version from *Help → About*.
- **Suggest features.** Open an issue after a look at the [roadmap](ROADMAP.md).
- **Ask questions or share how it felt.** Open an issue.
- **Report security issues** privately, as described in [SECURITY.md](SECURITY.md).

Issues are public, so please keep your own writing, story names and private details out of them.

By submitting an issue, suggestion or other feedback you agree to the terms of the [LICENSE](LICENSE).

## For invited collaborators

See the README for how to build and test the app.

- Everything the window asks for is checked in the main process. The window is never trusted with a path, a key or a decision.
- Keep personal content out of the repository: no real names, writing or private details in code, tests, screenshots or notes.
- Say what you couldn't check in the pull request, such as Windows or Mac behaviour.
